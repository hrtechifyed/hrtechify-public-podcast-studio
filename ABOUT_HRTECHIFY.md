# About HRTechify

**HRTechify — People • Technology • Growth**

HRTechify explores how people, technology and organisations can work better together. The Public Podcast Studio is an HRTechify open-source product designed to make professional podcast creation more accessible while keeping creators in control of their voice, branding and storage.

## Why this project exists

Podcast production often combines recording, editing, branding, rendering and file management across multiple tools. HRTechify Public Podcast Studio brings those steps into one transparent workflow.

The project is intentionally open source so developers can inspect how it works, contribute improvements, report problems and help shape the product.

## Creator-first product principles

- The creator's show identity remains primary.
- Users control where permanent media is stored.
- Original recordings are preserved.
- Spoken-content edits require user approval.
- Users can apply their own branding and templates.
- Every generated podcast video visibly carries **Podcast Powered by HRTechify** in the bottom-right corner as platform attribution.

## Open development

This repository is public by design. Contributions are welcome through issues and pull requests, subject to the project's contribution, security and code-of-conduct guidelines.
