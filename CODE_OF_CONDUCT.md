# Code of Conduct

HRTechify Public Podcast Studio welcomes contributors with different backgrounds, experience levels and perspectives.

## Expected behavior

Contributors should:

- Communicate respectfully and focus criticism on ideas and code rather than people.
- Assume good intent while remaining precise about technical and product risks.
- Welcome newcomers and explain context when possible.
- Respect privacy and never expose user data, credentials or confidential information.
- Avoid harassment, discriminatory language, threats, personal attacks or deliberately disruptive behavior.
- Keep issues and pull requests relevant to the project.

## Maintainer responsibilities

Maintainers may edit, hide, close or remove contributions that violate these expectations, contain sensitive information or create a security/privacy risk.

Repeated or serious violations may result in removal from project spaces or blocking from participation.

## Scope

This code applies to repository issues, pull requests, discussions, reviews and other project-managed community spaces.
